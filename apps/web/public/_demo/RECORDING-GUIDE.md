# دليل فيديو الديمو — Entrustic Beauty

الفيديو بيتولّد أوتوماتيك من 4 خطوات. مفيش مونتاج يدوي، ومفيش برامج مونتاج.

```
apps/web/public/_demo/
├── voiceover.json   ← النص المصري (12 سطر)   ← عدّل هنا لو عايز تغيّر الكلام
├── voiceover.py     ← بيسجّل الصوت + بيحسب مدة كل مشهد
├── music.py         ← بيعمل الموسيقى الخلفية
├── gen.cjs          ← بيولّد 12 صفحة HTML (مشهد لكل صفحة)
├── record.cjs       ← بيفتحهم في Chrome ويصوّرهم إطار بإطار
├── mux.cjs          ← بيدمج الصوت + الموسيقى مع الفيديو
├── logo.png         ← اللوجو المستخدم في الفيديو
├── shots/           ← تسجيلات وصور الشاشات
└── video/entrustic-beauty-demo.mp4   ← الناتج النهائي
```

## الأمر الكامل

```powershell
cd apps/web/public/_demo

python voiceover.py    # 1. الصوت + المدد  → voice/narr-XX.mp3 + timing.json
python music.py        # 2. الموسيقى        → audio/bed.wav
node   gen.cjs         # 3. المشاهد         → scenes/*.html + manifest.json
node   record.cjs      # 4. التصوير         → video/_raw.mp4   (~7 دقائق)
node   mux.cjs         # 5. الدمج           → video/entrustic-beauty-demo.mp4
```

بعد أي تعديل في النص: من 1 لـ 5.
بعد أي تعديل في التصميم/الترتيب: من 3 لـ 5.
بعد تغيير صورة أو تسجيل في `shots/`: `node record.cjs` ثم `node mux.cjs`.

## إزاي المزامنة مضمونة

`voiceover.py` بيقيس مدة كل سطر بالظبط ويكتبها في `timing.json`.
`gen.cjs` بياخد المدة دي ويطوّل المشهد عليها (0.4s قبل الكلام + 0.5s بعده).
يعني الصوت هو اللي بيحدد طول الصورة — مش العكس. مستحيل يحصل انزياح.

## إزاي الصورة مش بتهتز

`record.cjs` مش بيسجّل بالوقت الحقيقي (ده اللي كان بيخلّي الإطارات تقع).
هو بيطلب من الصفحة تقف عند لحظة محددة بالظبط: `window.__frame(t)`، وبعدين ياخد لقطة.

- كل أنيميشن CSS بيتوقف ويتحرّك للّحظة `t` بالظبط.
- الفيديوهات اللي جوه الكارت بيتعملها `seek` لنفس اللحظة.
- النتيجة: نفس الفيديو بالظبط كل مرة، مهما كانت سرعة الجهاز.

السرعة: ~100 مللي/إطار (JPEG q96، لأن PNG بيكلّف 450 مللي في 1080p).

## الشاشات: تسجيل حقيقي مش صورة

لو حطيت في `shots/` ملف **MP4** بنفس اسم الصورة (مثلاً `laser.mp4`)، الفيديو
هيستخدم التسجيل الحقيقي جوه الكارت والشاشة هتتحرك فعلًا.
لو مفيش MP4، بيستخدم الصورة PNG مع حركة تقريب بطيئة (ken-burns).

| الشاشة | المصدر الحالي |
|---|---|
| لوحة التحكم | `dashboard.png` (ثابتة) |
| سجل الحالات | `patients.png` (ثابتة) |
| الليزر | `laser.mp4` ✅ |
| الحقن | `injectables.mp4` ✅ |
| العناية بالبشرة | `skincare.mp4` ✅ |
| الباقات | `packages.png` (ثابتة) |
| المواعيد | `appointments.mp4` ✅ |
| الفواتير | `invoices.mp4` ✅ |
| المخزون | `inventory.png` (ثابتة) |
| التقارير | `reports.mp4` ✅ + `audit.png` |

> عايز المشاهد الثابتة تتحرك؟ سجّل 5 ثواني من الشاشة (سكرول + كليك) بصيغة mp4
> بنفس الاسم وحطها في `shots/`، وبعدين `node record.cjs && node mux.cjs`.

## الصوت

- الصوت: `ar-EG-SalmaNeural` (صوت مصري) على `+10%` سرعة.
- النص **لازم** يفضل بالمصري. الفصحى بتتقرأ فصحى وتبان غلط:
  «لوحة تحكم» ❌ → «الشاشة الرئيسية» ✅
  «الإيراد» ❌ → «الدخل» ✅
  «المحصّل» ❌ → «اللي اتقبض» ✅
  «تنبيهات المخزون» ❌ → «نواقص المخزن» ✅
- الموسيقى متولّدة بـ numpy (مفيش حقوق نشر): باد + بلّك + كيك + شيكر على 84 BPM.
  بتتحط على −28dB وبتوطى لوحدها لما الصوت يتكلم (sidechain ducking).
- المخرج النهائي على −16 LUFS.

## اللوجو

اللوجو في `_demo/logo.png`. مهم: اللوجو الأصلي **غامق** (كحلي/أسود)، فبيتحط
دايمًا على كارت كريمي فاتح — لو حطيته على الخلفية الغامقة مباشرة مش هيبان.

لو عندك لوجو جديد: استبدل `logo.png` وشغّل `node gen.cjs && node record.cjs && node mux.cjs`.

## تعديل المشاهد

كل حاجة في مصفوفة `scenes` في `gen.cjs`:

| الحقل | المعنى |
|---|---|
| `kind` | `hero` غلاف — `split` نص + شاشة — `duo` شاشتين — `outro` ختام |
| `tag` | الوسم الصغير فوق العنوان |
| `title` | العنوان (`\n` = سطر جديد) |
| `sub` | الوصف |
| `bullets` | ٣ نقاط قصيرة |
| `media` | `{type:'video'|'image', src, start, rate}` |

`start` = من الثانية كام في التسجيل، `rate` = سرعة التشغيل (0.85 = أبطأ شوية).

## المواصفات

- 1920×1080، 30 إطار/ثانية، H.264 + AAC
- المدة ≈ 80 ثانية
- الحجم ≈ 8–15 ميجا
- بيتفتح مباشرة على واتساب / يوتيوب / فيسبوك / إنستجرام
