# دليل تصوير الشاشات (للفيديو)

قبل أي حاجة، افتح الموقع:

```
https://entrustic-beauty.vercel.app
```

الدخول:

- **الإيميل:** `owner@demo.entrusticbeauty.app`
- **الباسورد:** `Demo#Owner2026!`

---

## القواعد المهمة (اقراها الأول)

1. **خلّي عرض المتصفح 1920 بالظبط** — أو أكبر. اضغط `F11` عشان تملأ الشاشة.
   لو الشاشة أصغر من 1920، صوّر على أكبر دقة عندك وسيب الباقي عليّا.
2. **استنى التحميل يخلص.** لو شفت مستطيلات رمادية متحركة (skeleton) استنى لحد ما تختفي.
3. **صوّر بـ `Win + Shift + S`** → اختار `Rectangular` → اسحب من فوق الشاشة لتحت.
   أو استخدم أداة `Snipping Tool`.
4. **الصيغة PNG.** الأداة بتحفظ PNG تلقائياً.
5. **متصوّرش الشريط العلوي بتاع المتصفح** (العنوان والتابات). صوّر محتوى الصفحة بس.
6. **مش لازم كلهم.** أي شاشة تسيبها، الفيديو هيستخدم الصورة القديمة بتاعتها.

## الأسماء بالظبط (مهم جداً)

الفولدر:

```
apps\web\public\_demo\shots\
```

حطّ الصورة بنفس الاسم ده بالحرف:

| حطّ اسم الملف | الشاشة اللي تفتحها من القائمة |
|---|---|
| `dashboard.png` | لوحة التحكم |
| `patients.png` | سجل الحالات والعملاء |
| `laser.png` | جلسات الليزر وإزالة الشعر |
| `injectables.png` | البوتوكس وحقن الفيلر |
| `skincare.png` | العناية ببشرة الوجه والماسكات |
| `packages.png` | باقات وعروض الجلسات |
| `appointments.png` | المواعيد والحجوزات |
| `invoices.png` | الفواتير والمالية والخزينة |
| `inventory.png` | المخزون والمستلزمات |
| `reports.png` | التقارير اليومية |
| `audit.png` | سجل الرقابة والأمان |

**مثال:** لو صوّرت لوحة التحكم، سمّي الملف `dashboard.png` وحطّه في الفولدر
وهو هيستبدل القديم. لو اسم مختلف (زي `dashboard (1).png`) الفيديو مش هيلاقيه.

## إيه اللي يخلي اللقطة حلوة؟

- **الداشبورد:** خلّي الكروت الأربعة (الحالات، مواعيد اليوم، الإيراد، الأجهزة) كلهم ظاهرين.
- **سجل الحالات:** خلّي الجدول فيه صفوف كتير (8–10 صفوف) — بيبان إن فيه داتا حقيقية.
- **الليزر / الحقن:** خلّي نسبة التقدّم والجلسات المتبقية ظاهرة.
- **الفواتير:** خلّي فيه فاتورة مدفوعة وفاتورة عليها متبقي — بتبيّن إن النظام بيحسب صح.
- **التقارير:** ده اللي فيه الأرقام — خليه واضح ومقروء.
- **المخزون:** خلّي تنبيه المخزون المنخفض ظاهر لو موجود.
- **سجل الرقابة:** خلّي التواريخ والأسماء العربية ظاهرة.

---

## خطوات التصوير

1. سجّل دخول.
2. افتح الشاشة من القائمة الجانبية.
3. استنى التحميل.
4. `Win + Shift + S` → اسحب.
5. بعد ما تتصوّر، هتلاقي إشعار — دوس عليه يفتح الـ Snipping Tool، واعمل `Ctrl + S`،
   وسمّيه بالاسم الصح، واحفظه في فولدر `shots`.
6. كرّر لكل شاشة.
